# Week 12 Capstone Project Gap Analysis

## Project Selection

### Selected Project

CrediTrust Complaint Assistant - RAG System

### Why I Selected This Project

I selected the CrediTrust Complaint Assistant RAG System because it combines
AI engineering, full-stack software development, and financial domain knowledge.

The project solves a real-world financial sector problem by helping analysts
understand customer complaints using Retrieval-Augmented Generation (RAG),
semantic search, and large language models to provide evidence-based answers.

This project aligns with my career goal as a Full-Stack Developer and AI
Engineer. The Week 12 improvements will focus on code quality, testing,
CI/CD, documentation, and reliability to transform it into a
production-ready portfolio application that demonstrates both technical
skills and business value.

# Summary of Main Gaps

The current project successfully implements a Retrieval-Augmented Generation
pipeline and interactive Streamlit interface.

The gap analysis identified several areas required to achieve production
readiness:

- Improve code maintainability through refactoring and type annotations.
- Increase reliability through automated testing.
- Introduce CI/CD practices for continuous quality checks.
- Improve documentation for easier adoption and reproducibility.
- Strengthen communication of business impact for finance-sector users.
